# Versa — визуальная система

Основа — цвета из [CSS официального сайта Казахтелекома](https://telecom.kz/css/main/app.css?id=893116bac7306d6083f3): #0095DA (знак логотипа), #20A2DE (основные кнопки), #121820 (текст), белый.

Градиент #0067B1 → #0095DA → #20A2DE и голубые свечения — адаптация для Versa, не утверждённая спецификация брендбука. Официальный логотип компании не воспроизводится; название Versa — название прототипа для задачи компании.

Шрифт — Roboto variable, локальный файл assets/Roboto.ttf, с поддержкой кириллицы. Текст документов 17–18 px с интерлиньяжем 1.9; названия документов 18–20 px. Документ 1, документ 2 и пояснение занимают 37%, 37%, 26% таблицы.

Красный оставлен для текстовых изменений. Удаление — красный зачёркнутый текст; дополнение — красный жирный текст. Статус дополнительно обозначен словами, чтобы различие не зависело только от восприятия цвета. Заголовки колонок закреплены при прокрутке; на узком экране таблица прокручивается горизонтально, сохраняя три колонки.

## Уточнение по референсам пользователя

Использованы присланные изображения кампании BAIGE 5G с telecom.kz: насыщенные синие блоки, тёмно-синие жирные заголовки, светло-голубые карточки, белые округлые кнопки и объёмные предметные иллюстрации. В Versa это компактный синий первый блок, два объёмных листа на CSS и контрастная шапка таблицы. Палитра адаптации: #0C457F, #1684D7, #35AFE5, #D6E8F5, #EFF3F6. Эти оттенки не заявляются официальной спецификацией брендбука. Макет сохраняет приоритет читаемой сравнительной таблицы; рекламные изображения и логотипы не копируются.
