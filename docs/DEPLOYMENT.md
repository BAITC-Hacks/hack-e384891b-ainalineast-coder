# Публичная версия Versa

Подготовлена сборка для статического HTTPS-хостинга. По состоянию на 23 сентября 2026 года публичная версия не опубликована. Та же логика Python исполняется внутри Web Worker через Pyodide 0.27.7. Пользовательские документы и результаты сравнения остаются в памяти вкладки браузера. Word, Excel, PDF, HTML, CSV и JSON формируются для прямого скачивания без серверного хранения.

При первом использовании требуется Интернет для загрузки Python WebAssembly и библиотек с CDN jsDelivr и PyPI. Документы этим сервисам не передаются. После закрытия вкладки состояние сравнения теряется; нужные результаты следует скачать. Опциональная серверная модель Ollama в браузерной версии недоступна. Требуется современный браузер с WebAssembly и Web Workers.

## Сборка и проверка

Из корня проекта выполните:

    python -B build_site.py
    python -m http.server 8766 --bind 127.0.0.1 --directory dist

Откройте http://127.0.0.1:8766/. Загрузите два документа либо синтетический пример, сравните, проверьте таблицу, заключение и скачивание DOCX/XLSX/PDF. Исходная локальная серверная версия по-прежнему запускается командой python app.py.

Сборщик копирует только разрешённый набор ресурсов. В публичную сборку не попадают пользовательские отчёты, архивы, временные файлы, ключи и предоставленные реальные положения. Демонстрационный пример в публичной версии синтетический. Реальные документы доступны в конкурсном репозитории и локальной версии.

## Публикация

Основной репозиторий: BAITC-Hacks/hack-e384891b-ainalineast-coder, ветка main. Включение GitHub Pages в нём требует прав администратора, которых у подключённого аккаунта нет. Подготовлена конфигурация отдельного статического хостинга Sites; публикация остановлена по запросу пользователя. Публичная ссылка отсутствует; каталог dist является готовым результатом сборки. Идентификатор существующего сайта находится в .openai/hosting.json. Повторно создавать сайт не требуется.

Для GitHub Pages этот же каталог dist можно публиковать как артефакт GitHub Actions после включения Pages администратором. Все пути относительные и поддерживают размещение по адресу /имя-репозитория/.

Обновление сайта: сохраните точное состояние исходников в BAITC, соберите dist, передайте это же состояние в технический репозиторий хостинга, сохраните версию и опубликуйте её. Не включайте токены доступа в исходники или файлы конфигурации. Проверяйте статус публикации и полный сценарий по внешнему адресу.
