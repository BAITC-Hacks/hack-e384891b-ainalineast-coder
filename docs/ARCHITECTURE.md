# Архитектура Versa

Главный сценарий новой версии: два документа → полный парсер пунктов → взаимно-однозначное сопоставление → diff по словам → таблица «Документ 1 / Документ 2 / Что изменилось». Модуль comparison.py сохраняет все фрагменты обеих редакций; основной порядок берётся из документа 1. Неизменённые строки остаются в таблице. Дополнительный анализ функций описан ниже.

Браузер → локальный HTTP API → извлечение текста → пункты и владельцы → сопоставление всего комплекта → правила отклонений → проверяемые источники → экспертное решение → экспорт.

## Контракт доказательств
Каждый фрагмент получает ID из версии, документа и локального номера; содержит название документа, пункт, извлечённый текст и владельца. Каждый вывод содержит evidence с исходными фрагментами. Отчёт использует эти же записи: цитаты не генерируются моделью. Номера строк относятся к преобразованному тексту, не к страницам исходного Word/PDF.

## Сопоставление
Нормализация Unicode, пунктуации, окончаний слов и явно указанного владельца; точные совпадения; отбор десяти кандидатов по словам; оценка сходства слов и последовательностей. Поиск выполняется по всему комплекту после изменений. Изменение номера не считается потерей. Изменение владельца отражается как перенос.

## Правила
Не найдено соответствие → кандидат потери. Близкие действия у разных владельцев → возможное пересечение. Совмещение исполнения и проверки сходного объекта → возможный самоконтроль. Изменение запрета или обязательности → отдельное замечание. Для примера внутреннего аудита учитывается разрешение участия в органах управления вместе с мерами независимости из того же пункта.

## Agentic workflow и модель
Оркестратор последовательно выполняет разбор, подбор соответствий, опциональную локальную LLM-проверку, правила отклонений и проверку ссылок. В автономном режиме LLM не применяется. Ollama ограничена фиксированным локальным endpoint, JSON-контрактом, выбранными кандидатами и проверкой буквальных цитат. Она не выполняет команды и не получает инструменты. При сбое используется честно обозначенный автономный результат.

## Безопасность и хранение
Нет CDN, внешней аналитики, пользовательских аккаунтов и отправки документов во внешнее облако. POST из чужого браузерного Origin отклоняется. Статическая раздача ограничена разрешёнными ресурсами. Текст экранируется при отображении и экспорте. CSV защищается от формул в начале ячеек. Экспорты сохраняются в отдельной папке, имена назначает сервер. Не предназначено для прямой публикации в интернете.

## Развитие после хакатона
OCR схем и сканов, локальные многоязычные embeddings и reranker, разметка RACI, граф слияний/разделений, версионированная база решений, RBAC, журнал согласования, оценка precision/recall на независимо размеченном корпусе. Эти возможности не выдаются за уже реализованные.
