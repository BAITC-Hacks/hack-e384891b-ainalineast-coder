## Ответы жюри
- **Где ИИ?** Готов дополнительный маршрут локальной языковой модели с проверкой источников. Текущая автономная демонстрация использует лексические алгоритмы и правила. Не утверждать, что LLM использовалась, если интерфейс показывает обратное.
- **Как защищены данные?** Локальная обработка; опциональная модель тоже локальная; экспорты остаются на компьютере.
- **Как измерена точность?** Есть поведенческие и контрольные тесты. Промышленная точность не измерялась; для неё нужен независимо размеченный корпус.
- **Почему дубль только возможный?** Сходные обязанности могут быть разделены по объектам и уровням. Окончательное решение принимает владелец процесса.
- **Бизнес-эффект?** Проверяемое сокращение ручного поиска и подготовки заключения — гипотеза для пилота. Не заявлять вымышленные проценты экономии.
