# Соответствие заданию и критериям

Веса взяты из предоставленного Markdown задания, а не восстановлены по обрезанным скриншотам.

| Критерий | Баллы | Что предъявить |
|---|---:|---|
| Соответствие задаче и работоспособность | 25 | Два комплекта, полная сравнительная таблица, подразделения, кандидаты потери/дублей/конфликтов, источники, заключение |
| Техническая реализация | 25 | Реальный код алгоритма, интерфейс, опциональный Ollama, проверка ID и цитат; честное указание используемого режима |
| README и воспроизводимость | 25 | Запуск одной командой, отсутствие обязательных ключей, demo data, автоматические проверки, verify.py |
| Ценность и применимость | 15 | Прослеживаемость ответственности и готовое заключение для согласования |
| Развитие и оригинальность | 10 | Сопоставление перенесённых пунктов, контроль обязательности, разделение факта из источника и решения эксперта |

## Must have
1. Подразделения: перечни §3.4 и явно заданные владельцы; впервые появившиеся/сохранившиеся/не найденные подразделения.
2. Функции: сопоставление всего комплекта, переносы и кандидаты отсутствия.
3. Пересечения: разные владельцы и потенциальный самоконтроль.
4. Источники: для каждого замечания — название, пункт и фрагмент.
5. Заключение: понятный HTML с цитатами, рекомендациями и статусом проверки.

## Требования к сдаче
Самостоятельный запуск проверяющими; актуальные исходники; README с установкой, зависимостями, параметрами и проверочным сценарием; раскрытие сторонних компонентов. На скриншотах часть текста обрезана — дополнительных невидимых условий и баллов не предполагаем.

## Не заявляем реализованным
OCR оргсхем, внешнюю нормативную проверку, бенчмаркинг операторов, промышленную точность, полностью автоматическое установление юридического факта реорганизации. Указанные ограничения доступны в README и заключении.
