# Использованные компоненты и происхождение

| Компонент | Использование | Лицензия / статус |
|---|---|---|
| Python 3 и стандартная библиотека | HTTP, JSON, ZIP/XML, CSV, алгоритмы, тесты | Python Software Foundation License |
| pypdf 6.10.0, необязательно | Извлечение текстового слоя PDF | BSD-3-Clause; лицензия входит в пакет |
| Ollama, необязательно | Локальное исполнение модели | MIT; устанавливается отдельно |
| Модель Ollama, необязательно | Предложение семантических соответствий | Зависит от выбранной модели, веса не включены |
| HTML, CSS, JavaScript | Собственный интерфейс | Внешние UI-библиотеки и шаблоны не использованы |
| Редакции 8 и 9 | Демонстрационные документы | Обезличенные материалы, предоставленные пользователем; отдельная открытая лицензия не заявляется |
| Контрольный пример | Проверка заранее известных отклонений | Синтетические данные, созданные для прототипа |

Проект создан с использованием OpenAI Codex и ИИ-помощи при программировании, анализе предоставленных текстов, подготовке документации и тестировании. Основная логика и интерфейс разработаны в рамках этой рабочей сессии; готовый сторонний продукт не использовался как собственная разработка.

ИИ-сгенерированный код требует проверки команды. В текущей версии эта проверка включает автоматические тесты, анализ реальных входных документов и браузерную проверку основного сценария. Наличие работающих тестов не означает сертификацию или промышленную готовность.

Ollama и веса моделей не распространяются с проектом. Разрешения на публикацию предоставленных документов за пределами конкурсного репозитория должны определяться их владельцем.
